# SMS Integration - Step by Step

To make the SMS Agent visible on your website, we need to create a place to store messages.

## Step 1: Create 'messages' Table (Supabase SQL)
Run this SQL in your Supabase Dashboard -> SQL Editor:

```sql
CREATE TABLE IF NOT EXISTS messages (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  created_at TIMESTAMPTZ DEFAULT NOW(),
  from_number TEXT,
  to_number TEXT,
  content TEXT,
  direction TEXT, -- 'inbound' (User) or 'outbound' (Isabelle)
  status TEXT DEFAULT 'sent'
);
```
